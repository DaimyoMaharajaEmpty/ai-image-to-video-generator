## 🚨 Symptoms of a Broken Image-to-Video Pipeline

Before you generate another clip, check whether your pipeline suffers from any of these classic symptoms. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 😵 Flickering frames | No interpolation | Frame interpolation |
| 🐌 Slow generation | CPU only | GPU pipeline |
| 🧊 Static output | No motion prompt | Motion control |
| 🔥 Blurry frames | Wrong model | Model selection |
| 📉 Audio out of sync | No mux | FFmpeg mux |
| 🔇 Short clips | No extend | Loop + extend |

> **💡 Tip:** If your clips flicker, add frame interpolation before exporting — it smooths most AI artifacts.
